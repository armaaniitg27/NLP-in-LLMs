# Notes on the project files

The annotation notes and reports use plain wording so the review decisions are easy to follow. The project author reviewed the annotations against the questions, generated answers, and retrieved context. The generated answers and experimental outputs are kept as recorded. Labels are not changed just to improve presentation, and uncertain cases remain marked as uncertain when the available text is incomplete. The earlier-results folder contains older outputs for comparison; some figures may differ from the recalculated summaries.
