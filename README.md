# NLP-in-LLMs
This repository contains my NLP project “Same Question, Different Prompts: How Prompt Variability Affects RAG Retrieval and the Question of Hallucination.”

the presentation video link: https://youtu.be/YW27er1Dcn0

**The codes folder contains all the relevant python codes I used to obtain results**, excluding all the intermediate unnecessary scripts i used to check my laptop's limits or stuff like that.

**The results folder contains all the results obtained, as CSVs and Excel Workbooks.**
The final report and final presentation are also attached.

**All codes can be run with a few specific instructions and prerequisites:**

Optional: {1) create a virtual environment with "**python -m venv venv**" 2) activate it "**venv\Scripts\activate**"}

3) install relevant libraries:
   
**pip install torch,
pip install transformers,
pip install sentence-transformers,
pip install faiss-cpu,
pip install pandas,
pip install numpy,
pip install scikit-learn,
pip install tqdm**

5) BEFORE RUNNING ANY SCRIPT, CHECK THE INPUT AND OUTPUT PATHS. I may have put a localised specific path for my own pc, change it according to your own pc. Also, I ran most of this on my own laptop's GPU, which has CUDA cores.

I am not sure if this will work on linux/Mac, but it will definitely work on Windows.
